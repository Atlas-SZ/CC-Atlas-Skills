# CodeFlow - 代码架构智能分析

## 概述

CodeFlow 是一个纯浏览器端运行的代码架构分析工具，核心文件仅一个 `index.html`（基于 Tree-sitter WASM + D3.js）。
它能将任意代码仓库转化为交互式架构图，帮助快速理解陌生代码库的结构与风险。

**核心价值：** 节省 Claude Code 在代码探索阶段的 token 消耗（探索阶段通常占复杂任务的 40-60% token）。

## 工作流程

### Step 1: 启动 CodeFlow

打开本地的 CodeFlow HTML 文件：

```bash
open ~/.claude/skills/codeflow/assets/index.html
# 或直接在浏览器打开
```

也可以使用在线版本（需要网络）：https://codeflow-five.vercel.app/

### Step 2: 选择分析方式

根据用户需求选择：

**方式 A - 本地文件夹（推荐，完全离线）：**
1. 在 CodeFlow 界面点击 "Open Folder"
2. 选择项目根目录
3. 等待分析完成（通常 10-60 秒）

**方式 B - GitHub 仓库：**
1. 在输入框粘贴 GitHub 链接（如 `facebook/react` 或完整 URL）
2. 私有仓库需要配置 GitHub Personal Access Token
3. 等待分析完成

### Step 3: 交互式探索

分析完成后，引导用户使用以下功能：

| 功能 | 用途 | 操作指南 |
|------|------|---------|
| 依赖图 | 查看文件间连接关系 | 点击节点高亮依赖，支持拖拽缩放 |
| 爆炸半径 | 评估修改影响范围 | 选择任意文件，查看影响文件数量 |
| 代码所有权 | 找到模块负责人 | 基于 Git 历史，显示主要贡献者 |
| 安全扫描 | 检测漏洞 | 自动检测硬编码密钥、SQL注入、eval 使用 |
| 模式检测 | 识别设计模式 | Singleton/Factory/Observer/反模式 |
| 健康评分 | 代码质量评级 | A-F 等级（死代码/循环依赖/耦合度/安全问题） |
| 活动热力图 | 识别活跃模块 | 按提交频率着色 |
| PR 影响 | 分析 PR 影响范围 | 粘贴 PR 链接查看影响文件 |

### Step 4: 导出报告供 Claude 消费

点击顶部 "Export" 按钮导出 JSON 报告，保存到项目目录：

```bash
# 建议保存路径
<project_root>/_codeflow_report.json
```

### Step 5: Claude 消费报告（核心能力）

当项目中存在 `_codeflow_report.json` 时，自动读取并提取以下信息作为工作上下文：

1. **架构概览：** 文件数量、语言分布、健康评分
2. **依赖关系：** 模块间调用链、循环依赖
3. **风险点：** 安全问题、死代码、高耦合模块
4. **修改影响：** 目标文件的爆炸半径

读取报告后，将关键发现整理为结构化摘要，替代 Glob/Grep/Read 反复探索，
直接进入具体文件阅读和修改阶段。

## 支持的语言

JavaScript, TypeScript, Python, Java, Go, Ruby, PHP, Vue, Svelte, Rust, C/C++, C#, Swift, Kotlin 等 30+ 种语言。

## 可视化模式

| 模式 | 说明 |
|------|------|
| 文件夹 | 按目录结构着色 |
| 层级 | 按架构层级着色（UI/Services/Utils） |
| 变更频率 | 按提交频率着色（热点区域） |
| 爆炸半径 | 选择文件后按影响范围着色 |

## 隐私

- 100% 浏览器端运行，代码不上传
- GitHub Token 仅存于浏览器内存，关闭标签页即清除
- 本地文件夹分析完全离线

## 典型使用场景

### 场景 1: 接手新项目

```
用户: "我刚接手了一个 Django 项目，帮我快速了解架构"
执行:
1. open codeflow/assets/index.html
2. 引导用户拖入项目文件夹
3. 分析完成后，读取健康评分和依赖图
4. 输出: 架构概要 + 核心模块 + 风险点 + 建议
```

### 场景 2: 重构前评估

```
用户: "我想重构用户认证模块，帮我评估影响"
执行:
1. 用 CodeFlow 分析项目
2. 选择 auth 相关文件，查看爆炸半径
3. 导出报告，读取依赖关系
4. 输出: 影响范围 + 风险等级 + 推荐策略
```

### 场景 3: 代码审查辅助

```
用户: "审查这个 PR 的架构影响"
执行:
1. 在 CodeFlow 中粘贴 PR 链接
2. 查看 PR 影响的文件和爆炸半径
3. 结合安全扫描和模式检测结果
4. 输出: 架构级审查意见
```

## 注意事项

- GitHub API 速率限制: 无 Token 60次/小时，有 Token 5000次/小时
- 大型仓库（10K+ 文件）分析可能需要几分钟
- 本地文件夹分析无速率限制，完全取决于文件数量
- 导出 JSON 报告是连接 CodeFlow 和 Claude 的关键桥梁
